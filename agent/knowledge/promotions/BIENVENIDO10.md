# Cupón BIENVENIDO10 — Bienvenida: 10% de descuento en el primer pedido

## Condiciones de validez

| Condición | Detalle |
|---|---|
| Descuento | 10% sobre el total del pedido |
| Importe mínimo | €30,00 (antes del descuento) |
| Aplicable a | Primer pedido únicamente |
| Restricción de cuenta | Cuenta registrada hace menos de 90 días |
| Acumulable | NO — no se combina con ningún otro cupón ni oferta |
| Productos excluidos | Artículos de outlet y liquidación |
| Caducidad del código | Sin fecha límite mientras el programa esté activo |

## Instrucciones para el agente: cómo diagnosticar

Si el operador reporta que BIENVENIDO10 no aplica el descuento, **pregunta lo siguiente antes de responder**:

1. ¿El importe del pedido (sin el descuento) es de €30,00 o más?
2. ¿Es realmente el primer pedido de esa cuenta? ¿El cliente podría tener otra cuenta con pedidos anteriores?
3. ¿El pedido incluye artículos de outlet o de liquidación? (aparecen con la etiqueta "OUTLET" en la ficha de producto)
4. ¿Hay algún otro cupón o código de descuento aplicado en el mismo pedido?
5. ¿La cuenta fue creada hace menos de 90 días?

## Diagnóstico según respuestas

- **Importe < €30** → el cupón requiere un mínimo de €30. Solución: añadir más productos hasta alcanzar el mínimo.
- **No es el primer pedido** → el cupón solo aplica al primer pedido de cada cuenta. No se puede aplicar en pedidos posteriores.
- **Cuenta con más de 90 días** → el programa BIENVENIDO10 es solo para cuentas recientes. En este caso no aplica.
- **Hay artículos de outlet en el carrito** → los artículos de outlet están excluidos. Si hay mezcla con artículos de colección regular, el cupón puede aplicar solo sobre estos últimos (comprobar en el desglose del carrito).
- **Otro cupón activo** → no acumulable. Debe elegir entre BIENVENIDO10 u otro cupón.
- **Todo correcto pero sigue sin aplicar** → escalar: posible bug técnico en el motor de descuentos.
